# ScamShield - Frontend

React + TypeScript + Vite frontend for scam detection application.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Create `.env` file:
```bash
cp .env.example .env
```

3. Configure API URL in `.env`

4. Run development server:
```bash
npm run dev
```

5. Build for production:
```bash
npm run build
```

## Features

- Message/URL/Email scam analysis
- Real-time AI chat advisor
- Scan history tracking
- Privacy mode (no history saved)
- Scam reporting
- Dark mode support

## Tech Stack

- React 18
- TypeScript
- Vite
- TailwindCSS
- Framer Motion
- React Query
- React Router
